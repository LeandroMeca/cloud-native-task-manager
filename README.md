# cloud-native-task-manager
API RESTful Cloud-Native e escalável para gestão de tarefas. Desenvolvida em Java (Spring Boot 3) e orquestrada via Docker Compose. Integra infraestrutura AWS (S3, EC2, Lambda) para eventos e armazenamento, com stack completa de Observabilidade (Prometheus/Grafana) para monitoramento HTTP em tempo real.
